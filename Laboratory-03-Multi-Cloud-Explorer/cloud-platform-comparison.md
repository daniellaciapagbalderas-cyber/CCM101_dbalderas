## Analysis Questions

**Which cloud provider offers the broadest range of services?**
AWS offers the broadest range of services, with over 200 fully featured offerings covering nearly every category of cloud computing. Its long head start since 2006 has allowed it to build the most mature and extensive service catalog of the three providers.

**Which provider best integrates with Microsoft technologies?**
Microsoft Azure best integrates with Microsoft technologies, since it is built by the same company that produces Windows Server, Active Directory, and Microsoft 365. Organizations already using these tools can adopt Azure with minimal friction through native compatibility and hybrid cloud options like Azure Arc.

**Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud Platform is strongest in both areas. It created Kubernetes and its managed service, Google Kubernetes Engine (GKE), is widely regarded as the most refined container orchestration platform. GCP also leads in AI/ML tooling through products like Vertex AI and TensorFlow, which were both developed by Google.
