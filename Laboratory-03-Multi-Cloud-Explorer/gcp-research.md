# Google Cloud Platform Research

## Brief Overview
Google Cloud Platform (GCP) is Google's suite of cloud computing services, launched in 2008. It leverages the same infrastructure Google uses for products like Search and YouTube, and is especially known for strength in data analytics, machine learning/AI, and Kubernetes/container orchestration (which Google originally created).

## Global Infrastructure
- Regions: 40+ regions worldwide
- Availability Zones: 120+ zones
- Edge Locations: 200+ (via Google's global network/CDN)

## Cloud Management Console
The Google Cloud Console is a web-based UI for managing GCP resources, projects, and billing. It provides an intuitive dashboard, built-in Cloud Shell for command-line access directly in the browser, and organizes resources by "Projects" for access control and billing separation.

![GCP Console](./screenshots/gcp-homepage.png)

## Four (4) Core Services
1. **Compute Engine** – Scalable virtual machines for running workloads, GCP's equivalent to EC2/Azure VMs.
2. **Cloud Storage** – Object storage for unstructured data, with multiple storage classes (Standard, Nearline, Coldline, Archive) based on access frequency.
3. **Cloud SQL** – Fully managed relational database service supporting MySQL, PostgreSQL, and SQL Server.
4. **Cloud Functions** – Serverless, event-driven compute for running lightweight code without managing servers.

## Three (3) Advantages
1. Industry-leading data analytics and AI/ML tools (BigQuery, Vertex AI, TensorFlow integration).
2. Creator and operator of Kubernetes — Google Kubernetes Engine (GKE) is considered the gold standard for managed Kubernetes.
3. Competitive, often simpler pricing model with sustained-use discounts applied automatically.

## Typical Enterprise Use Cases
- Big data analytics and business intelligence with BigQuery
- Machine learning and AI application development
- Containerized application deployment using Kubernetes
