# Microsoft Azure Research

## Brief Overview
Microsoft Azure is Microsoft's cloud computing platform, launched in 2010. It is deeply integrated with Microsoft's enterprise software ecosystem (Windows Server, Active Directory, Microsoft 365, .NET), making it the preferred choice for organizations already invested in Microsoft technologies.

## Global Infrastructure
- Regions: 60+ regions worldwide (more than any other major cloud provider)
- Availability Zones: Available in most major regions
- Edge Locations: 190+ (via Azure CDN)

## Cloud Management Console
The Azure Portal is a web-based, unified console for building, managing, and monitoring Azure resources. It offers dashboards, resource groups for organizing related resources, and integrates directly with Azure Active Directory for identity and access management. Azure CLI and PowerShell are also available for automation.

![Azure Console](./screenshots/azure-homepage.png)

## Four (4) Core Services
1. **Azure Virtual Machines** – On-demand, scalable virtual servers similar to EC2, supporting Windows and Linux.
2. **Azure Blob Storage** – Object storage service for unstructured data such as documents, images, and backups.
3. **Azure SQL Database** – Fully managed relational database-as-a-service built on Microsoft SQL Server.
4. **Azure Functions** – Serverless compute service for running event-driven code without managing infrastructure.

## Three (3) Advantages
1. Seamless integration with Windows Server, Active Directory, and Microsoft 365 — ideal for hybrid enterprise environments.
2. Strong hybrid cloud support through Azure Arc and Azure Stack, letting organizations run workloads on-premises and in the cloud together.
3. Enterprise agreements and licensing benefits for existing Microsoft customers.

## Typical Enterprise Use Cases
- Hybrid cloud deployments for organizations with existing on-premises Microsoft infrastructure
- Enterprise identity and access management via Azure AD
- .NET application hosting and DevOps pipelines with Azure DevOps
